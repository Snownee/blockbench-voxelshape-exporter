# VoxelShape Exporter

VoxelShape Exporter exports the cubes of your Java Block model as a Minecraft VoxelShape (1.14+ modded). It is the VoxelShape export feature extracted from the JTK222's Mod Utils plugin into a standalone plugin, with improved usability.

## Installation

File -> Plugins... -> Load Plugin from URL -> https://raw.githubusercontent.com/Snownee/blockbench-voxelshape-exporter/refs/heads/master/plugins/voxelshape_exporter/voxelshape_exporter.js
